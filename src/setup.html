Flyby setup

Give Flyby read-only access to your Google Calendar — about 5 minutes, one time.

Good news: there's nothing to deploy and no server to run. Flyby lives entirely in your browser. This setup just creates a free Google “key” (a Client ID) so Flyby can read your calendar. You can even skip it for now: open a normal website tab and click ✈️ Send a test flight in the popup to watch the plane right away.
Where does the plane fly? Over normal websites. Chrome doesn't let any extension draw on its own pages (the New Tab page, chrome://… pages, the Web Store, or PDFs), so on those Flyby shows a desktop notification instead. The popup tells you when the current tab is one of these.

  1. Copy this extension's ID

    Flyby is already loaded, so it has an ID. Copy it — you'll paste it into Google in step 5.

    (open this page from the Flyby popup to see your ID)

    You can also find it at chrome://extensions on the Flyby card.

  2. Create a Google Cloud project

    Open the Google Cloud Console and create a project (any name, e.g. “Flyby”). Free.

  3. Turn on the Calendar API

    Go to APIs & Services → Library, search Google Calendar API, and click Enable.

  4. Set up the consent screen

    Go to APIs & Services → OAuth consent screen. Choose External, add an app name and your email, and under Test users add your own Google address.

    Testing mode is fine — it means only you can sign in, which is all you need. Add the scope .../auth/calendar.events.readonly if it asks.

  5. Create the OAuth Client ID

    Go to APIs & Services → Credentials → Create credentials → OAuth client ID.

    Application type: Chrome Extension (older consoles call it Chrome app). Paste your extension ID from step 1 into the Item ID field, then create it.

  6. Paste the Client ID into Flyby

    Copy the new Client ID (it ends in .apps.googleusercontent.com) and put it in manifest.json:

    "oauth2": {
  "client_id": "YOUR_CLIENT_ID.apps.googleusercontent.com",
  "scopes": ["https://www.googleapis.com/auth/calendar.events.readonly"]
}

    Save the file, then on chrome://extensions click the reload ↻ icon on Flyby.

  7. Connect and fly

    Click the Flyby icon → Connect Google Calendar → approve. Pick your lead times (5 or 10 minutes), and you're done.

🎉 That's it — no deployment needed

Flyby now watches your primary calendar and flies a banner across your screen a few minutes before each meeting. Everything runs locally; your calendar data never leaves your browser.

Changed your mind? Click Disconnect in the popup to revoke access anytime.
